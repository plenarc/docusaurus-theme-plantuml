---
description: PR の CI とチェックリストを検証し、すべて通過したら draft を解除する。
---

## 1. CI の確認

- `gh pr checks` で CI の完了を待ち、**success / failed を明示**する。
- failed かつコードで対応可能なら `coder` サブエージェントに修正させ、再 push を促す(push はユーザー本人が行う)。

## 2. チェックリストの消化

- PR 本文のチェックリストのうち、コードで着手できる項目を実施し、チェックを付ける。

## 3. ユーザー確認項目

- ユーザー自身が確認・対応すべき項目は「確認してください」と促す。

## 4. draft 解除

- **全チェック通過 かつ CI 通過** を確認したら `gh pr ready` で draft を解除する。

## 5. 案内

「Merge 可能です」と伝える。
